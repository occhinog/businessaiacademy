# BusinessAI.academy

Static single-page website for [businessai.academy](https://businessai.academy/).

## Structure

- `index.html` — page content and semantic structure
- `assets/style.css` — all site styling and responsive rules
- `assets/*.webp` — hero and gallery images
- `CNAME` — GitHub Pages custom-domain configuration

The site does not currently need JavaScript.

## Local preview

From the repository root:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
